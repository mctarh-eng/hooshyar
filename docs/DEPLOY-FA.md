# 🖥️ راهنمای انتشار هوش‌یار روی سرور

این راهنما قدم‌به‌قدم توضیح می‌دهد چطور وب‌اپ هوش‌یار را روی سرور منتشر کنی و APK اندروید را به آن وصل کنی.

---

## 🧭 نقشه‌ی کلی — چه خبر است؟

```
گوشی کاربر ──► APK هوش‌یار (پوسته‌ی امن WebView)
                        │
                        │  HTTPS ← آدرس سرور تو (CAP_SERVER_URL)
                        ▼
        سرور تو: Next.js + دیتابیس SQLite + کلید AI
                        │
                        ▼
              سرویس هوش مصنوعی (GLM/Z.AI)
```

اپ اندروید فقط «پوسته» است؛ **مغز اپ (هوش مصنوعی، تاریخچه، تصویرسازی) روی سرور اجرا می‌شود.** پس برای اینکه APK واقعاً کار کند، باید وب‌اپ روی یک آدرس HTTPS منتشر شود.

### چیزی که لازم داری:

| # | نیاز | توضیح | هزینه تقریبی |
|---|---|---|---|
| ۱ | **کلید API هوش مصنوعی** | از سرویس GLM/Z.AI بگیر (پنل کاربری → API Keys) | پلن رایگان موجود است؛ پلن پولی هم ارزان |
| ۲ | **یک سرور یا هاست** | گزینه‌های پایین‌تر — از ایران قابل دسترس باشد | بسته به انتخاب |
| ۳ | **دامنه یا ساب‌دامنه با HTTPS** | لیارا رایگان می‌دهد؛ روی VPS با Caddy رایگان می‌شود | ۰ |

> ⚠️ **واقعیت مهم:** بدون سرور، APK فقط پوسته است و صفحه‌ی آفلاین می‌بینی. اگر فعلاً نمی‌خواهی سرور راه بیندازی، کاربران می‌توانند از همان آدرس وب به‌صورت PWA نصبش کنند (نیاز به سرور دارد) — یا صبر کن تا سرور آماده شود.

## 🅰️ گزینه‌ی A — لیارا (ساده‌ترین راه، پیشنهاد ما)

لیارا یک پلتفرم ایرانی است؛ دامنه‌ی HTTPS رایگان (`*.liara.run`) می‌دهد، از ایران بدون فیلترشکن باز می‌شود و اپ Docker ما را مستقیم اجرا می‌کند.

### قدم‌به‌قدم

**۱) نصب CLI لیارا:**
```bash
npm install -g @liara/cli
liara login          # با حساب لیارا وارد شو (ثبت‌نام در liara.ir)
```

**۲) ساخت اپ:**
```bash
liara app create hooshyar --platform docker --region iran
```
در سوال «پورت» مقدار `3000` را بزن. (می‌توانی از داشبورد `app.liara.ir` هم اپ بسازی — گزینه‌ی **Docker** را انتخاب کن.)

**۳) اتصال دیسک برای دیتابیس** (مهم! تا گفتگوها با ری‌استارت پاک نشوند):
- در داشبورد `app.liara.ir` → اپ **hooshyar** → تب **Disks**
- یک دیسک بساز با مسیر نصب (mount path): `/app/data`

**۴) تنظیم متغیرهای محیطی:**
```bash
liara env set ZAI_BASE_URL="https://api.z.ai/api/paas/v4" -a hooshyar
liara env set ZAI_API_KEY="کلید-تو-اینجا" -a hooshyar
```
یا از داشبورد → تب **Environment**.

**۵) انتشار:**
```bash
cd hooshyar            # ریشه‌ی پروژه
liara deploy -a hooshyar
```
لیارا خودش Dockerfile را می‌بیند، می‌سازد و اجرا می‌کند. بعد از چند دقیقه اپ روی `https://hooshyar.liara.run` (یا آدرسی که لیارا می‌دهد) بالا است. 🎉

**۶) تست سریع:**
```bash
curl https://hooshyar.liara.run/api/conversations
# باید [] برگرداند (لیست خالی) — یعنی سرور و دیتابیس زنده‌اند
```

### به‌روزرسانی بعدی
هر وقت کد عوض شد، فقط دوباره `liara deploy -a hooshyar` بزن.

## 🅱️ گزینه‌ی B — سرور مجازی ایران + Docker (کنترل کامل)

مناسب ParsPack، ابر آروان، اب‌اروان یا هر VPS لینوکسی (حداقل: ۱ گیگ رم).

### ۱) نصب Docker
```bash
curl -fsSL https://get.docker.com | sh
```

### ۲) دریافت کد و تنظیمات
```bash
git clone https://github.com/mctarh-eng/hooshyar.git
cd hooshyar
cp .env.example .env
nano .env    # ZAI_API_KEY را بگذار
```

### ۳) اجرا
```bash
docker compose up -d --build
```
اپ الان روی پورت `3000` سرور اجراست. دیتابیس در volume ذخیره می‌شود و با ری‌استارت نمی‌پرد.

### ۴) HTTPS با Caddy (رایگان و خودکار)
```bash
apt install -y caddy
nano /etc/caddy/Caddyfile
```
محتوای فایل (دامنه‌ی خودت را بگذار — رکورد A دامنه را به IP سرور وصل کن):
```
app.your-domain.ir {
    reverse_proxy localhost:3000
}
```
```bash
systemctl reload caddy
```
Caddy خودش گواهی HTTPS می‌گیرد و تمدید می‌کند. تمام! اپ روی `https://app.your-domain.ir` است.

> اگر دامنه نداری، فعلاً می‌توانی با `http://IP:3000` تست کنی — اما **برای APK حتماً HTTPS لازم است** (WebView اندروید HTTP ساده را بلاک می‌کند).

### به‌روزرسانی
```bash
cd hooshyar && git pull && docker compose up -d --build
```

### بکاپ دیتابیس
```bash
docker run --rm -v hooshyar_hooshyar-data:/data -v $(pwd):/backup alpine \
  cp /data/custom.db /backup/custom-backup.db
```

## 🌍 گزینه‌ی C — هاست‌های خارجی (Vercel و…)

**پیشنهاد نمی‌شود** برای مخاطب ایرانی، به این دلایل:
- تحریم: اکانت‌های ایرانی در Vercel/Netlify معمولاً مسدود می‌شوند
- دسترسی کاربران از ایران گاهی کند یا ناموفق است
- دیتابیس SQLite روی Vercel ماندگار نیست (باید دیتابیس جدا بگیری)

اگر با این محدودیت‌ها موافقی، همان Dockerfile روی هر ابر Japanese/European کوچکی (مثل Hetzner) هم کار می‌کند.

## 📱 وصل کردن APK به سرور

وقتی سرور بالا آمد و آدرس HTTPS داری:

1. برو به گیت‌هاب → مخزن `hooshyar` → **Settings → Secrets and variables → Actions**
2. تب **Variables** → متغیر `CAP_SERVER_URL` را با آدرس سرور بساز/ویرایش کن:
   ```
   https://hooshyar.liara.run
   ```
3. برو به تب **Actions** → ورک‌فلو **Build APK** → **Run workflow** (یا یک push/tag جدید بده)
4. APK جدید حالا به سرور تو وصل است — از Artifacts دانلود کن (یا اگر تگ `v*` بزنی، Release خودکار ساخته می‌شود)

> می‌توانی آدرس سرور را در همین چت بگو تا این کارها برایت انجام شود. 🙂

## 🩺 رفع اشکال

| مشکل | علت احتمالی | راه‌حل |
|---|---|---|
| اپ باز می‌شود ولی چت جواب نمی‌دهد | کلید AI تنظیم نشده | `ZAI_API_KEY` را در env بگذار و ری‌استارت کن |
| خطای `no .z-ai-config` در لاگ | متغیرها خالی‌اند | `ZAI_BASE_URL` و `ZAI_API_KEY` هر دو لازم‌اند |
| گفتگوها بعد از ری‌استارت پاک می‌شوند | volume/disk وصل نیست | دیسک `/app/data` (لیارا) یا volume کامپوز را چک کن |
| APK صفحه‌ی آفلاین می‌دهد | `CAP_SERVER_URL` اشتباه یا HTTPS نیست | آدرس باید با `https://` شروع شود و در مرورگر باز شود |
| `502 Bad Gateway` | کانتینر بالا نیامده | `docker compose logs -f` بگیر (یا لاگ لیارا) |
| HTTPS نمی‌آید | پورت ۸۰/۴۴۳ بسته است | در فایروال سرور باز کن: `ufw allow 80,443/tcp` |

**دیدن لاگ‌ها:**
```bash
docker compose logs -f          # روی VPS
liara logs -a hooshyar          # روی لیارا
```

## 🔐 نکته‌ی امنیتی

- کلید API فقط روی سرور می‌ماند و هرگز وارد APK/مرورگر نمی‌شود — همه‌ی درخواست‌های هوش مصنوعی از مسیر `/api/*` سمت سرور می‌روند
- فایل `.env` و `.z-ai-config` را هرگز کامیت نکن (در `.gitignore` هستند)
- اگر چند نفر استفاده می‌کنند و می‌خواهی مصرفت محدود بماند، در پنل سرویس AI سقف هزینه (spend cap) بگذار
